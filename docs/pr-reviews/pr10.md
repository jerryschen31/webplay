## 1. (packages/adapters/src/local.ts) caption BPM vs `--bpm` mismatch

`buildLocalPrompt` used the genre-profile BPM (e.g. 75) even when the
request carried an explicit BPM range, while `aceStepMusicalArgs` derived
the range midpoint (e.g. 85) for the `--bpm` flag — so the caption could
say "75 BPM" while the model received `--bpm 85`.

**fixed** (a906cef)
An explicit request BPM range now takes precedence over the profile
default in the caption too, matching the structured-arg precedence. Added
a test asserting the explicit range appears in the caption and the profile
default does not.

## 2. (apps/generator/py/acestep_generate.py) `--keyscale` forwards `""` not `None`

Concern: `keyscale=args.keyscale` forwards an empty string rather than
`None`, which "may not trigger auto-detection".

**reasoned decline**
Verified against the ACE-Step API: `GenerationParams.keyscale` is typed
`str = ""` (not `Optional`), and `inference.py` guards with
`if key_scale and key_scale.strip()`, so `""` is exactly the model's
auto-detect sentinel — passing `""` is identical to omitting the value,
and `None` would violate the field type. (`--bpm` is the genuinely
optional field, `Optional[int] = None`, and we do pass `None` there.)
No change needed.
